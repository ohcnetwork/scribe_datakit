Get started

Setup takes a few minutes and you only do it once. The app runs on your own computer.

  • Hugging Face accountFree. Create one if you don't have it.
  • GitDownload Git
  • Python 3.11 or newerDownload Python
  • Node 18 or newerDownload Node

  1. Ask for access

    Send the maintainer your Hugging Face username. They'll add you and send you the link to the code.

  2. Install and open the app

    Run this in a terminal, using the link from the maintainer. The first run takes a few minutes, then the app opens in your browser.

    git clone <link from the maintainer>
cd scribe_dump
make review

    On Windows, run this inside WSL. Next time, run make review from the same folder. Press Ctrl-C in the terminal to stop the app.

  3. Connect Hugging Face

    Open your access tokens, choose Create new token, pick the Write type and give it any name. Paste it into the app.

    The token stays on your computer. Don't share it with anyone, and don't paste it into a chat.

  4. Claim your first batch

    A batch is about 30 minutes of audio. Choose Claim and its audio downloads to your computer. Other reviewers will see it's taken.

Using Claude Code?

Open Claude Code in the scribe_dump folder and ask it to set up the review app. It will check your tools and start the app. You still paste the token into the app yourself.

Review a batch

Your work saves after each box, so you can stop and come back.

  1. Open a clip

    The waveform plays the whole recording. Each segment has its own play button for just that part.

  2. Check the languages

    Type what's really spoken, such as ml, en. Whisper's guess is often wrong. For English-only audio, the translation boxes disappear.

  3. Review each segment

    Listen, then fix the text. If it's already right, choose Accept as is. A box you don't touch isn't counted as reviewed.

  4. Choose Mark reviewed

    Each segment needs at least one reviewed box. If you're annotating in English only, you can leave the transcript boxes alone. The app then takes you to the next clip.

  5. Choose Submit batch

    Do this when every clip is done. It sends your work to the maintainer. Until then your work is only on this computer, so finish a batch on the machine you started it on.

Two small words changed the clinical meaning, and Whisper's version still read smoothly. That's why every line gets checked against the audio.

How to write the text

Transcript

Write what was said, in the language it was said, such as പനി ഇല്ല. Leave out "um" and false starts unless they change the meaning.

Translation

Translate what was said. Don't summarise, tidy up or add anything.

English words in other speech

Keep them in English letters, such as patient or paracetamol.

Can't make out a word

Write [unclear]. Don't guess.

Take extra care with these

Write numbers, units and doses exactly as spoken, and listen again if you're unsure. Doses, left and right, and negation such as "no fever" need the closest attention, because one wrong word changes the meaning.

The whole process

Where a recording goes, from upload to dataset release. Your part is highlighted.

  1. Maintainer

    Add a collection

    Recordings come in as a named collection.

  2. Automatic

    Cut into segments

    Each recording is split at pauses, up to 28 seconds per segment.

  3. Whisper

    Write the first draft

    Whisper produces a transcript and an English translation for each segment. This machine text is kept apart from your text and is never overwritten.

    pending
  4. Maintainer

    Publish batches

    Recordings are grouped into batches of about 30 minutes.

    pending
  5. You

    Review and submit

    You claim a batch, correct it against the audio and submit it.

    reviewed or flagged
  6. Maintainer

    Check and accept

    Your submission is checked, then added to the dataset with your username as the reviewer.

    reviewed
  7. QA reviewer

    Second check, if needed

    A QA batch starts from the first reviewer's text. The QA reviewer checks it against the audio, fixes anything wrong and chooses Mark QA complete.

  8. Maintainer

    Finalize

    Only the maintainer can mark a recording final.

    final
  9. Maintainer

    Release

    The dataset is published on Hugging Face for training and fine-tuning, including models that turn Malayalam and mixed-language clinical speech into English text.
